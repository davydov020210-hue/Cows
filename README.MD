### Шпаргалка по Markdown

| Что нужно | Как написать |
|---|---|
| Заголовок | `# H1`, `## H2`, `### H3` |
| Жирный | `**текст**` |
| Курсив | `*текст*` |
| Ссылка | `[текст](url)` |
| Картинка | `![alt](url)` |
| Код в строке | `` `code` `` |
| Блок кода | ```` ```python ... ``` ```` |
| Список | `- пункт` |
| Нумерованный | `1. пункт` |
| Цитата | `> текст` |
| Таблица | `\| a \| b \|` |
| Чек-бокс | `- [x] сделано` |
