### Шпаргалка по Markdown

| Что нужно | Как написать |
|---|---|
| Заголовок | `# H1`, `## H2`, `### H3` |
| Жирный | `**текст**` |
| Курсив | `*текст*` |
| Ссылка | `[текст](url)` |
| Картинка | `![alt](url)` |
| Код в строке | `` `code` `` |
| Блок кода | ```` ```python ... ``` ```` |
| Список | `- пункт` |
| Нумерованный | `1. пункт` |
| Цитата | `> текст` |
| Таблица | `\| a \| b \|` |
| Чек-бокс | `- [x] сделано` |

### Советы

1. **Пиши для будущего себя.** Через полгода ты забудешь, как запускать проект.
2. **Добавляй скриншоты или GIF.** Визуал цепляет.
3. **Не копируй чужой README целиком.** Адаптируй под свой проект.
4. **Обновляй README**, когда меняешь функционал.
5. **Для учебных проектов** достаточно: название, описание, как запустить, автор.
